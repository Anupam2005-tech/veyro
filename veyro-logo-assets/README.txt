# Veyro logo asset pack

Generated from the two supplied 1448x1086 RGBA logo files.

## Theme mapping
- `dark`: light/white mark intended for dark surfaces.
- `light`: dark mark intended for light surfaces.

## Contents
- `source/`: original assets and alpha-trimmed master marks.
- `icons/veyro-{theme}-{size}.png`: transparent square icons at 16, 32, 48, 64, 96, 128, 180, 192, 256 and 512 px.
- `icons/veyro-{theme}-pwa-{192|512}.png`: square PWA icons with a solid contrasting background.
- `icons/veyro-{theme}-maskable-512.png`: 512x512 maskable-style PWA icon with extra safe-zone padding.
- `icons/favicon-{theme}.ico`: multi-resolution ICO favicon (16, 32, 48, 64, 128 and 256 px).
- `social/veyro-og-{theme}-1200x630.jpg`: Open Graph/social preview image.

## Notes
The supplied logo is raster artwork, not vector artwork. No SVG has been fabricated.
Use one favicon/PWA theme consistently with the app's chosen browser/install theme, or select the appropriate variant where the platform supports it.
